The real payment sequence

Four verified steps.

  1. 01

    You open the bot

    This page uses a Telegram deep link. The bot receives a purchase request for the selected product.

  2. 02

    The bot sends an invoice

    The server creates a unique order and sends a Telegram Stars invoice with the product and price.

  3. 03

    Telegram completes checkout

    Telegram handles the Stars checkout. Your website and bot never receive card details.

  4. 04

    The purchase is delivered

    The server validates the payment update, stores its charge ID, then sends the configured file in chat.

★

Digital goods use Stars

Digital products and services sold inside Telegram use Telegram Stars with the currency code XTR.

✓

Payment is server-verified

The bot does not deliver from the browser or a pre-checkout approval. It waits for Telegram’s successful-payment update.

⌁

Orders are recorded

The starter stores the order payload and Telegram payment charge ID locally so duplicate webhook delivery does not resend the item.
