# Creative Starter Pack

These are 12 square (1080 × 1080) SVG social-media templates.

- Open an SVG in Figma, Canva, Adobe Illustrator, Inkscape, or a text editor.
- Replace the sample wording inside the `<text>` elements.
- Change the hex colours in the `<style>` block to match your brand.
- Export the finished design as PNG or JPG for posting.

The designs use common system fonts so they remain easy to edit on most devices.
